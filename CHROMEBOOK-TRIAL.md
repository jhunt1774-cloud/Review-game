# HP Chromebook visual trial

Upload all package contents to the repository root, replacing matching files. Open the normal game address with ?visualtest=1 at the end. Click Chromebook test encounter. This uses a separate save key and does not replace a student's normal adventure.

The longer Mossgate test fight has modest leaf animation and bounded attack/defense impact sparks. It reuses the established painted hero and enemy animations; new directional character sheets are not part of this test. Standard mode uses seven short impact particles, Light uses three and removes leaves. Combat timing and correctness rules are unchanged.

On an HP 11A G8 EE (16W64UT), play for about two minutes using attacks, skills, and defenses. Try Standard first, then Light. Click Download results while in battle and provide the resulting text file or its contents. Note whether movement or defense input feels delayed, whether sound crackles, and what other tabs are open. The readout is a rolling foreground animation-frame sample, not a measured guarantee for every chapter.

Targets: consistent 30 FPS or better, responsive defense input, readable UI at 1366 × 768. Actual HP Chromebook performance is not yet measured. Automated simulated checks verify isolated saving, counters, mode switching and lifecycle cleanup.
