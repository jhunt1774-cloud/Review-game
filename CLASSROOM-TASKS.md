# Grades 6–8 math: teacher review and classroom tasks

This RPG now targets middle school. The separately saved Grade 1 bank is reserved for another game. Fifth grade is not the current target.

The 1,600 prepared questions provide partial-skill practice. Review every question before assigning it. The questions have automated checks, but no independent educator review or student pilot. Mathematical practices, construction, modeling, evidence and explanation cannot be established by choosing a multiple-choice answer alone.

Suggested review process: check alignment with the full source standard, solve each item, check distractors and accessibility of the model, and try the set with a small group before broad use. Keep the status as Ready for teacher review until that review is actually done.

For classroom tasks, use a simple 0–2 scale for each of model/construction, mathematical accuracy, and explanation/transfer: 0 = not yet shown, 1 = shown with support, 2 = shown independently. This is a suggested local rubric, not a state-approved mastery score.
