# Release scope

One complete, independently saved forest adventure, with four required encounters, optional patrols, six caches, teacher-question support and free exploration after victory. The original game remains accessible. Other campaign regions have not been converted. No physical Chromebook certification is claimed; browser tests include reduced viewport size and CPU throttling.
