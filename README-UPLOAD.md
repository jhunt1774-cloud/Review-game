# Expansion-ready game

Upload the CONTENTS of this folder to the root of the existing GitHub repository, including index.html, every JS file, styles.css, assets and document-libs. Replace files of the same name; do not upload only index.html. Existing unrelated files do not need deletion. Your public game address and old assignment links remain the same. File versions in URLs help refreshed pages request updated assets.
